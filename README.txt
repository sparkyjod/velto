VELTO FINAL WEBSITE

Files: index.html (complete portfolio homepage)

Publish once:
1. Open your existing GitHub repository.
2. Replace the root index.html with this file.
3. In index.html, find VELTO_CONTACT_EMAIL and replace REPLACE_WITH_YOUR_EMAIL with your real email. Keep the quote marks.
4. Commit to the production branch (usually main).
5. Wait for Vercel deployment to show Ready, then test the live site.

Notes: Portfolio concept demos are illustrative. The contact enquiry form opens a prefilled email draft; the visitor must press Send. Menu and portfolio photography are externally hosted image URLs and need an internet connection.
